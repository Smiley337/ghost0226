# FLIP OUT! · A little chance

기존 GitHub Pages 저장소와 동일하게 HTML·CSS·JavaScript만 사용하는 영어 동전 던지기 게임입니다. 빌드나 패키지 설치 없이 `/dice/`에서 제공됩니다. 홈 메뉴의 **FLIP OUT!**으로도 이동할 수 있습니다.

[참고 사이트](https://dineer0919-tech.github.io/Jeolho-sCHANCE/)의 공개 HTML·CSS에서 확인한 먹색·종이색·금색 조합, 얇은 패널 테두리와 명조 제목을 책상 게임에 맞춰 적용했습니다. 원본 GIF는 이미 투명하므로 캐릭터만 보여 주며, 사용자 사진은 배경색을 채우지 않는 원형 크롭을 유지합니다. 게임 문구·설정·알림은 영어이며 차분한 안내 문구를 사용합니다. 기존 저장 키와 게임 수치는 유지합니다.

잔액 헤더는 페이지 전체에서 상단에 고정됩니다. 모바일에서는 브랜드와 잔액을 두 줄로 배치해 업그레이드까지 스크롤해도 재화를 확인할 수 있습니다. 재화는 `0.00`, `0.50`, `1,234.50`처럼 항상 소수 두 자리로 표시합니다. 잔액·보상·업그레이드 가격·나침반 미리보기 및 결과에 같은 형식을 적용합니다.

## 실행

저장소 루트에서 Node.js로 다음 명령을 실행하고 `http://127.0.0.1:4173/dice/`를 엽니다.

```powershell
node dice/tests/serve.cjs
```

GitHub Pages가 현재 저장소 루트를 게시하도록 설정되어 있다면 변경 파일을 기존 게시 브랜치에 반영한 후 `https://ghost0226.info/dice/`로 접근합니다. 별도 서버, 라우터 또는 빌드 설정은 필요하지 않습니다.

## 파일 역할과 임시 밸런스

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 책상·동전·나침반·업그레이드·사진 설정 화면 |
| `config.js` | 확률, 보상, 업그레이드 가격·증가량·상한, 대기 시간, 이미지 경로 |
| `core.js` | 추첨, 정확한 소수 정산, 입력 잠금, 저장 상태 복원 |
| `storage.js` | 게임 localStorage와 원본 사진 IndexedDB 저장 |
| `app.js` | 키보드·터치 입력, 3D 회전, 화면 갱신 |

초기 잔액은 0만두, 앞면은 50% 확률로 1만두, 뒷면은 50% 확률로 0.5만두를 받습니다. 모든 일반 던지기는 무료입니다.

| 업그레이드 | 첫 구매 비용 | 레벨당 효과 | 상한 |
| --- | --- | --- | --- |
| 행운 | 8만두 | 앞면 확률 +2.5%p | 90%, 16레벨 |
| 앞면 수익률 | 5만두 | 앞면 배율 +0.5 | 100레벨 |
| 뒷면 수익률 | 4만두 | 뒷면 배율 +0.25 | 100레벨 |
| 굴리는 속도 | 6만두 | 착지 후 대기 −0.04초 | 최소 0.1초, 10레벨 |

다음 구매 가격은 `첫 비용 × 1.6^현재레벨`을 올림합니다. 가격과 효과는 모두 `config.js`에서 조절합니다. 보상과 잔액의 실제 정산·저장에는 반올림을 적용하지 않습니다. 화면 표시만 소수 셋째 자리에서 반올림하며, 금액은 BigInt 기반 십진 연산으로 처리해 `0.1 + 0.2` 같은 부동소수점 오차를 방지합니다. 예를 들어 내부 잔액 `0.005`는 `0.01`로 표시하고, West ×5 뒤 내부 잔액 `0.025`는 `0.03`으로 표시합니다. 새로고침해도 내부 소수는 보존합니다. 대기 시간과 확률은 금액 표시와 분리되어 있습니다.

## 동작 및 저장

- 동전 클릭·탭 또는 스페이스로 던집니다. 공중 및 착지 후 대기 중에는 다시 던질 수 없습니다. 버튼·파일 입력·대화상자를 키보드로 조작할 때 일반 던지기는 실행되지 않습니다.
- 앞뒤 이미지가 붙은 3D 동전을 회전합니다. 뒷면의 로컬 180도 회전과 동전 자체 회전이 합쳐져 글자가 정상 방향으로 보입니다. 다음 던지기도 마지막 각도에서 이어집니다.
- 나침반 확인창을 열면 기준 잔액을 고정합니다. 확정 후 정수 0~99를 한 번만 뽑고, 0~48 North ×0.1 / 49~97 South ×1.5 / 98 East ×1 / 99 West ×5를 적용합니다. 확인·회전 중 던지기와 구매는 잠깁니다.
- 확정된 던지기·나침반 결과는 애니메이션 시작 전에 저장합니다. 회전 중 새로고침해도 재추첨 없이 해당 결과를 한 번 정산하고 저장합니다.
- 사진은 면별 최대 8MB의 PNG, JPG/JPEG, GIF를 지원합니다. 원본을 다시 인코딩하지 않아 GIF 애니메이션이 보존됩니다. 각 면을 독립적으로 복원할 수 있습니다.
- 잔액·레벨·마지막 면은 localStorage, 사진 Blob은 IndexedDB에 보관합니다. 사진을 서버로 보내지 않습니다. 다른 기기/브라우저/도메인에는 공유되지 않으며 사이트 데이터를 지우면 사라집니다. 저장 실패 시 화면에 안내합니다.

## 검증

핵심 정산·입력 처리·저장 예외 자동 테스트:

```powershell
node --test dice/tests/core.test.cjs dice/tests/app.test.cjs dice/tests/storage.test.cjs
```

브라우저 통합 테스트: 서버를 실행하고 `http://127.0.0.1:4173/dice/tests/browser.html`에서 **테스트 실행**을 누릅니다. 실제 게임 페이지를 별도 테스트 저장 키로 불러오므로 플레이 중인 저장 데이터에는 영향을 주지 않습니다.

필수 수동 확인:

1. 새 게임에서 뒷면이 나오면 잔액이 정확히 0.5만두 늘고 `0.50`으로 표시되는지 확인합니다.
2. 앞면 수익률을 구입했을 때 뒷면 지급액이 변하지 않고, 뒷면 수익률 구입 시 앞면 지급액도 그대로인지 확인합니다.
3. 나침반 확인창에 49%·49%·1%·1%가 나오며, 확정 중 구매·던지기를 할 수 없는지 확인합니다. 구간 경계와 네 방향 정산은 핵심 테스트에서 강제로 검증합니다.
4. 클릭과 스페이스를 연타하고 스페이스를 계속 누른 상태에서도 한 번의 던지기에 한 번만 지급되는지 확인합니다.
5. 서로 다른 사진을 앞뒤에 넣고, 뒷면 착지 시 실제 뒷면 사진이 남는지 확인합니다. 새로고침 뒤 사진·잔액·레벨·마지막 면이 복원되는지도 확인합니다.
6. 320px 모바일 화면과 데스크톱에서 동전 비행, 움직이는 GIF, 그림자, 거울 반전 없는 글자, 실제 나침반 바늘 정지 방향을 육안으로 확인합니다.
7. 모바일과 데스크톱에서 페이지 맨 아래까지 스크롤해도 헤더의 잔액·설정 버튼이 보이는지 확인합니다. 설정·나침반 대화상자는 헤더 위에 열려야 합니다.

`app.test.cjs`는 실제 게임 스크립트를 간단한 DOM 어댑터에서 실행하고, `storage.test.cjs`는 저장 API의 성공·실패를 주입해 검사합니다. 이 테스트는 실제 브라우저의 렌더링·이미지 해독·디스크 저장을 대신하지 않습니다.

현재 작업 환경에서는 Node 테스트와 실제 기본 GIF 파일의 원본 바이트 보존을 확인했습니다. 브라우저 제어 연결이 차단되어 실제 렌더링 및 브라우저 통합 테스트 실행 결과는 확인하지 못했습니다.
